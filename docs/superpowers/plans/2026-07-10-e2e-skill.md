# PRD 驱动 E2E Skill 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 发布一个单入口、多 Markdown 子流程的中文 PRD 驱动 E2E 浏览器验收 Skill。

**Architecture:** e2e/SKILL.md 是唯一触发入口，按状态机读取 11 个阶段文件；manifest 描述安装元数据，registry 只公开一个 e2e 条目，Vitest 对注册、文件、确认门和安全规则做发布契约验证。

**Tech Stack:** TypeScript、Vitest、JSON Schema、Markdown、Node.js。

## Global Constraints

- 仅新增 Agent Skill 文档和发布元数据；不实现 Playwright runtime、业务代码、网络调用或浏览器执行。
- e2e 是唯一注册 ID；阶段文件均是同目录 Markdown 子流程。
- 未完成验收范围确认不得生成确定性 Case；未完成执行契约确认不得执行浏览器动作。
- 生产默认只读；写或不可逆动作逐项授权；不可逆动作默认拒绝。
- 真实链路与故障注入必须分开；不得通过弱化断言、改 PRD 或 skip 让结果变绿。
- 不新增依赖，保持 tdd Skill 发布行为不变。

~~~text
prd-intake: PRD-ID, Revision, normalized PRD, manifest and diff only.
acceptance-scope: REQ scope, ambiguity, dependency and first confirmation only.
requirement-model: rules, actors, states, transitions and observable results only.
interaction-flow: expected UI flow and risks; never selectors.
coverage-cases: matrix, traceable CASE, 100% design-audit gate; no vague or duplicate cases.
execution-contract: URL, environment, identities, data, injection and second confirmation only.
browser-verification: preflight, binding, real/injected runs and redacted evidence; never alter expectations.
automation-healing: diagnostic order and at most two safe retries in allowed categories.
regression-assets: standard Playwright current, manifest, staging and atomic publish.
visual-report: fact-only Markdown/HTML and strict verdict.
artifact-protocol: schema-first artifacts, .biztest containment, staging/rollback and latest replacement.
~~~
