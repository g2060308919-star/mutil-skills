## 验收中发现并修复的问题

1. 协议的 requestId 允许小写、点、下划线和冒号，但发布 generation ID 只允许大写字母、数字和连字符。`create-run` 过去直接拼接短 requestId，可能直到 finalization 才失败。现在仅保留符合发布格式的短 ID，其他合法 requestId 使用确定性大写摘要派生 runId。
2. 跨仓发行驱动复制源码时遗漏 `.tmp` 排除规则，可能复制受信执行留下的只读临时文件并在清理时报 `EACCES`。现在 publication source 明确排除 `.tmp`。

两项修复均先增加失败回归测试，再完成实现并验证通过。
