## 已发现的报告设计缺陷

真实执行覆盖了 TC-01～TC-10，但当前正式资产只有一个聚合 Case、一个 Step 和一个 Action。中间状态断言全部进入同一个 `runnerResultDigest`，没有为每个 TC 分别保存独立 `actualDigest`、Evidence ID 和 Traceability Matrix 行。

因此本报告可以证明“聚合程序中的所有断言在真实网站上通过”，但不能声称“Runtime 已产生十个各自签名、各自有证据的独立 Case 结果”。高质量后续实现应把 PRD 功能拆成独立 Requirement/Rule/Oracle/Case，或为一个 Case 的每个 Step 持久化 checkpoint observation、actual value digest 与 evidence refs。
