# E2E Runtime 0.3.1 Workspace Golden 验收报告

## 验收结论

逐场景的真实网站操作、实际观察值、Run/Attempt/Result 标识与证据摘要见：[TodoMVC 真实 PRD 详细验收报告](./e2e-0.3.1-todomvc-detailed-validation-report-2026-07-26.md)。

- **Runtime 全链路：通过（accepted）。** 0.3.1 从十四个 workspace tarball 安装到全新 HOME 和空白用户项目后，可在源码仓不可用、用户项目 `node_modules` 已移除的条件下，通过正式 `repo-e2e rpc`、系统 Google Chrome、一次性 Profile 和 Gateway 完成执行、Cleanup、Reload、证据密封及报告发布。
- **full-playwright 能力矩阵：通过。** 已验证表单输入、键盘、Popup、多页面/多 Context、带 JSON Body 的写请求、独立 Cleanup 和 Cleanup 后 Reload。
- **公开 PRD 业务验收：通过，但目标产品存在一项规格偏差。** TodoMVC TypeScript+React 的功能、持久化和清理均通过；其 localStorage key 为 `react-todos`，不符合 PRD 的 `todos-[framework]` 命名要求。该偏差属于目标产品，不属于 Runtime 链路失败。
- **npm Registry 安装：本报告不宣称通过。** 0.3.1 尚未发布到 Registry，因此发布后仍须另跑 Registry Golden，并单独提交 Registry 验收报告。

```text

  → REQ-TODOMVC-FUNCTIONAL

  → ORACLE-TODOMVC-FUNCTIONAL
  → COV-TODOMVC-FUNCTIONAL
```

## 双重 Verdict

### Runtime verdict：accepted

Runtime 已证明能从固定 PRD 生成可审查语义资产，冻结执行与网络边界，在真实浏览器完成组合动作，独立清理并 Reload 复核，再生成带摘要和实体链路的可追踪报告。

### TodoMVC 产品 verdict：accepted-with-deviation

TC-01 至 TC-10 所需业务行为、持久化和清理均通过。唯一偏差是 localStorage key `react-todos` 不符合 PRD 的 `todos-[framework]`；报告不得把该偏差归因于 Runtime，也不得将产品表述为完全符合 PRD。

## 发布后剩余门禁

0.3.1 发布到 npm 后，必须用 `E2E_RUNTIME_GOLDEN_PACKAGE_SOURCE=registry` 在另一套全新 HOME 中安装十四个精确版本，并逐包核对 Registry lockfile integrity 与本次 tarball 的 SHA-512。只有该命令通过后，才能新增并签署 `0.3.1 Registry Golden` 报告；本报告不能替代发布后门禁。
